06 · Frontend

Animation Strategy

Purposeful motion — every animation earns its place.

Page Transitions
Use Framer Motion's AnimatePresence with a 0.3s fade + slight upward slide on route change. Replace the old 4-second blocking loader entirely. First visit only: 0.8s brand intro animation.
Scroll Reveals
All section cards use whileInView with once: true and staggered children via variants. Opacity 0→1, Y +20→0. Triggers when 20% of element is in view.
Navbar Scroll Effect
On scroll past 60px, navbar background transitions from transparent to rgba(13,17,23,0.95) with backdrop-blur. Logo scale increases slightly. Use useScroll from Framer Motion.
Hover Micro-interactions
Project cards: subtle Y -4px translate + border glow on hover. CTA buttons: copper fill slides up from bottom (existing pattern — keep it, it works). Nav links: copper underline scales in from left.
Hero Text Animation
Headline words stagger in one by one (0.08s delay between each) using Framer Motion's variants with staggerChildren. Only fires once on mount — not blocked by loader.
Performance Rules
Only animate transform and opacity — never layout properties like height, width, or padding. Use will-change: transform on animated cards. Respect prefers-reduced-motion.

09 · Backend

API Reference

All 18 endpoints. Base URL: https://api.zentryhub.in/api

Authentication

POST /auth/login Admin login. Returns JWT in httpOnly cookie. Rate limited to 10 req/15min.
POST /auth/logout Clears the auth cookie. Protected route.
GET /auth/me Verify JWT and return admin info. Used by frontend to check login state.

Projects

GET /projects All published projects. Optional query: ?category=AI&featured=true
GET /projects/:id Single project by ID.
POST /projects Create new project. 🔒 Admin only. Accepts multipart/form-data (image upload to Cloudinary).
PUT /projects/:id Update project. 🔒 Admin only.
DELETE /projects/:id Delete project. 🔒 Admin only. Also deletes image from Cloudinary.

Testimonials

GET /testimonials All approved testimonials only. Public.
GET /testimonials/pending All pending (unapproved) submissions. 🔒 Admin only.
POST /testimonials Public submission. Goes into pending queue. Rate limited to 3/hour per IP.
PUT /testimonials/:id/approve Approve a pending testimonial. 🔒 Admin only.
DELETE /testimonials/:id Delete testimonial (approve/reject action). 🔒 Admin only.

Contact / Leads

POST /contact Submit contact form. Saves to leads table + sends email notification via Resend. Rate limited to 5/hour per IP.
GET /leads All contact submissions. 🔒 Admin only. Sorted by created_at desc.
PUT /leads/:id/read Mark lead as read. 🔒 Admin only.
⚠
All 🔒 Admin only routes require the JWT cookie to be present and valid. The middleware checks it before the route handler runs. If the cookie is missing or expired, return 401 immediately.
10 · Backend

Authentication System

Simple, secure, no third-party auth service needed.

Login Flow
1. Admin POSTs email + password to /auth/login
2. Server finds admin by email, compares password with bcrypt
3. On match: sign a JWT (7-day expiry) with admin ID as payload
4. Set JWT in httpOnly cookie (not localStorage — prevents XSS)
5. Return 200 + admin info (without password hash)
Protected Routes
Every admin API route uses an authMiddleware that:
1. Reads the JWT from req.cookies.token
2. Verifies it with jwt.verify(token, JWT_SECRET)
3. Attaches admin to req.admin
4. Calls next() — or returns 401 if invalid/missing
Frontend Guard
ProtectedRoute.jsx calls GET /auth/me on mount.
If 401 → redirect to /admin/login
If 200 → render children (dashboard)
Shows a spinner during the check. Never shows dashboard content before auth is confirmed.
Brute Force Protection
Rate limit /auth/login to 10 attempts per 15 minutes per IP using express-rate-limit.
After 10 fails: return 429 with a "Too many attempts" message.
Never reveal whether email or password was wrong — always say "Invalid credentials."

12 · Infrastructure

Security Checklist

Non-negotiable items before going live.

Helmet.js on all routes
Sets Content-Security-Policy, X-Frame-Options, X-XSS-Protection, and 12 other headers in one line: app.use(helmet()). Blocks most common web attacks.
CORS restricted to your domain
Only allow requests from https://zentryhub.in. Block all other origins. Never use origin: '*' in production.
Passwords hashed with bcrypt
Use salt rounds of 12. Never store plain text. Never log passwords. The admin user is created via a one-time seed script.
JWT in httpOnly cookie
Not in localStorage (XSS vulnerable). Set secure: true (HTTPS only) and sameSite: 'strict'. 7-day expiry.
Input validation on all routes
Use Zod or express-validator on every POST/PUT body. Reject unexpected fields. Validate email format, rating range, string lengths. Never trust client input.
Rate limiting on sensitive routes
Login: 10 req/15min. Contact form: 5 req/hour. Testimonial submit: 3 req/hour. All per IP. Prevents brute force and spam.
Prisma prevents SQL injection
Prisma uses parameterised queries by default. Never use raw SQL with user input. The ORM handles escaping automatically.
Admin route hidden from UI
Remove the "LOGIN" link from the public navbar entirely. The /admin/login URL is known only to you. ProtectedRoute handles unauthorised access attempts.

SEO & Analytics

Be findable. Be measurable.

React Helmet (SEO meta tags)
Install react-helmet-async. Set unique <title> and meta description per page. Add Open Graph tags so LinkedIn/WhatsApp shares show a preview card. Critical for Indian B2B clients who share links on WhatsApp.
Sitemap & robots.txt
Create public/robots.txt — allow all, disallow /admin. Generate sitemap.xml with all public routes. Submit both to Google Search Console after launch.
Core Web Vitals targets
LCP < 2.5s: serve images via Cloudinary with WebP. FID < 100ms: no blocking scripts. CLS < 0.1: define image dimensions. Use Vite's code splitting — each route is a lazy-loaded chunk.
Analytics: Plausible or Umami
Both are free, open-source, GDPR-compliant alternatives to Google Analytics. No cookie banner needed. Umami can be self-hosted on Railway for free. Shows visitors, pages, referrers, countries.
